# Phase 0 — Foundations

> Goal: build the CS and security base everything else stands on.

## Concepts to learn

- How computers work: binary, memory, CPU, processes
- Operating system basics: file systems, permissions, user/kernel space
- What is confidentiality / integrity / availability (CIA triad)
- Authentication vs authorization
- Symmetric vs asymmetric encryption, hashing, TLS basics
- How the internet works: IP, DNS, HTTP, TCP/UDP

## Practice

- Set up a VM (VirtualBox / virt-manager) with Kali + a target (Metasploitable, DVWA, or a stock Debian box)
- Complete a beginner CTF: [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) (Linux + bash fundamentals)
- Finish the free tier of [Cisco Networking Academy "Intro to Cybersecurity"](https://www.netacad.com/courses/intro-cybersecurity) or equivalent

## Done when

- [ ] You can explain the CIA triad and give an example of each failure
- [ ] You can describe what happens when you type a URL and press Enter (DNS → TCP → TLS → HTTP)
- [ ] You've completed Bandit levels 0–10
