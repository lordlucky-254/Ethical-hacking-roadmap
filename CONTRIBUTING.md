# Contributing

Contributions that make this roadmap more accurate, accessible, and safety-conscious are welcome.

## Ways to help

- Correct typos, broken links, and outdated references.
- Suggest a clearer learning sequence or explain prerequisites.
- Add reputable learning resources, especially free and hands-on defensive material.
- Improve accessibility, formatting, and explanations for beginners.
- Add lab-only examples that help readers understand concepts safely.

## Responsible security boundaries

- Practice only in systems you own, intentionally vulnerable labs, or targets covered by explicit written authorization.
- Keep examples and screenshots free of real personal information, credentials, private infrastructure, or undisclosed findings.
- Do not submit instructions or code designed to attack real targets, evade monitoring, steal data, or disrupt services.
- Do not test any external system while preparing or reviewing a contribution.

## Before opening a pull request

- [ ] Keep the change focused and explain why it improves the roadmap.
- [ ] Verify references and links; prefer primary or authoritative sources.
- [ ] Mark lab-specific steps clearly and include the required authorization context.
- [ ] Remove secrets and identifying information from examples.

Thanks for helping people learn cybersecurity responsibly.
