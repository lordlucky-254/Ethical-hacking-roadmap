# Phase 0 — Foundations

> Goal: build the CS and security base everything else stands on.

## Concepts to learn

- how computers work (binary, memory, CPU, processes)
- OS basics (file systems, permissions, user/kernel space)
- CIA triad
- authentication vs authorization
- symmetric vs asymmetric encryption, hashing, TLS basics
- internet basics (IP, DNS, HTTP, TCP/UDP)
